# BOSS GX-100 over MIDI

Everything here comes from the official *GX-100 MIDI Implementation* (Roland,
ver 1.10, 2022-03-03). It is worth reading the source once:
<https://static.roland.com/assets/media/pdf/GX-100_MIDI_Implementation.pdf>

## What the pedal listens to

| message | detail |
|---|---|
| channel | acts on messages matching `MENU:MIDI:MIDI SETTING:RX CHANNEL` |
| bank select | CC#0 (MSB), values **0–2 only**, then CC#32 (LSB) = 0 |
| program change | 0–127, resolved through the pedal's own `MENU:MIDI:PROGRAM MAP` |
| assign sources | CC#1–31, CC#33–63, CC#64–95 |
| MIDI clock | followed when `MENU:MIDI:MIDI SETTING:SYNC CLOCK` ≠ `INTERNAL` |

After power-up the unit behaves as if bank 0 were selected, until it receives a
bank select message.

## The program-map gotcha

**A program change does not name a memory.** It names a *slot*, and the pedal's
internal PROGRAM MAP decides which memory that slot points at. Three banks of
128 slots, each able to point at any memory 0–299 — `U01-1`…`U50-4` (200 user)
then `P01-1`…`P25-4` (100 preset).

So `config/gx100.yaml` has to mirror what is actually programmed into the pedal.
With `sequential_default: true` we assume the straightforward layout:

| bank | PC | memory |
|---:|---:|:---|
| 0 | 0 | U01-1 |
| 0 | 1 | U01-2 |
| 0 | 3 | U01-4 |
| 0 | 4 | U02-1 |
| 0 | 127 | U32-4 |
| 1 | 0 | U33-1 |

```
rambass gx100 map --limit 40
```

prints the table. **Verify a couple of rows against the pedal before trusting
it**: send PC 4 and check that `U02-1` lights up. If it does not, either
reprogram the pedal's PROGRAM MAP to match, or list the real mapping under
`assignments:` in `config/gx100.yaml` — the tool will use it instead of the
sequential assumption.

## Programming patch changes

In `song.yaml`, or with the CLI:

```
rambass patch 04-titolo 1  U01-1 --name "clean"
rambass patch 04-titolo 25 U02-3 --name "chorus crunch"
rambass gx100 midi 04-titolo
```

Memories are written the way they are printed on the pedal (`U02-3`), so the
manifest matches what the guitarist sees. Each change becomes a CC#0 → CC#32 →
program change triplet in `midi/gx100.mid`.

### The 120 ms lead

Every change is sent **120 ms early** by default (`--lead-ms`). Switching a
memory is not instantaneous; a patch that lands exactly on the downbeat arrives
late. A hair early is inaudible, a hair late is a missed entry. Increase it if
the pedal still feels behind — the only cost is that the tail of the previous
patch gets cut slightly sooner.

## Wiring it up

Route the **GX-100 MIDI** track's output to the pedalboard's MIDI input (USB or
the MIDI jack). In Reaper: set the track's MIDI hardware output to the GX-100,
and set the track's channel to match `gx100.channel` in `song.yaml` and the
pedal's RX CHANNEL.

## Tempo-synced effects for free

Because the pedal follows MIDI timing clock when `SYNC CLOCK` is not
`INTERNAL`, sending clock from Reaper makes every tempo-synced delay, tremolo
and modulation lock to the backing track — per song, automatically, without
programming a single delay time. Enable **Options > Preferences > MIDI Devices >
[your interface] > Send clock/SPP to this device** in Reaper, and set the
pedal's SYNC CLOCK to `MIDI` or `USB`.

This is probably the single biggest sound win available here for the least work.

## The pedal as a controller

The GX-100 also *transmits* program change and CC on its TX channel, controlled
by `MENU:CONTROL/ASSIGN:MEMORY MIDI`. So a memory switch on the pedalboard can
drive Reaper's transport (see docs/reaper.md) — the guitarist starts the next
song with their foot and never touches the laptop.

Pick one direction. If Reaper is sending patch changes to the pedal *and* the
pedal is sending program changes back to Reaper, you have built a loop. Also
check `MIDI IN THRU` / `USB IN THRU`: when either is anything other than `OFF`
the pedal retransmits what it receives, which is another way to build the same
loop.

## Expression control

CC#1–31, #33–63 and #64–95 are recognised as assign sources, so a CC automation
lane in Reaper can ride a parameter — wah position, delay level, whammy — from
the backing track. Set `MENU:ASSIGN SETTING:SOURCE` on the pedal to the CC
number you intend to use. The pedal maps incoming values through its ACT
LOW/HIGH range, so a full 0–127 sweep in Reaper is not necessarily a full sweep
of the parameter.

## The patch sheet

```
rambass gx100 sheet --setlist gig --out gx100-sheet.md
```

One row per change, in running order, with bar, timecode, memory, bank and PC.
Print it and tape it to the pedalboard — when the MIDI does not arrive mid-set,
that sheet is how the changes get made by foot instead.
